Google Drive

Your marks and notes are written as tidy Markdown files, one per book, in a Dogear folder in your Drive. They update automatically as you read.

Setup (one time)
  1. Open Google Cloud → APIs & Services → Credentials, create a project if asked.
  2. Enable the Google Drive API under “Enabled APIs & services”.
  3. Create an OAuth client ID of type Web application. Add this site’s origin () to “Authorized JavaScript origins”.
  4. Configure the consent screen (External, add yourself as a test user) with scope drive.file.
  5. Paste the client ID below.

Dogear only asks for the drive.file scope: it can see and edit only files it created.
