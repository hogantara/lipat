Google Drive

Marks and notes are written as Markdown files, one per book, in a Lipat folder in your Drive. They update as you read.

Setup (one time)
  1. Open Google Cloud, APIs & Services, Credentials and create a project if asked.
  2. Enable the Google Drive API under “Enabled APIs & services”.
  3. Create an OAuth client ID of type Web application. Add this site’s origin () to “Authorized JavaScript origins”.
  4. Configure the consent screen (External, add yourself as a test user) with scope drive.file.
  5. Paste the client ID below.

Lipat only asks for the drive.file scope: it can see and edit only files it created.
